# shahaf (Sail Trainer 3D)

**What it is:** a 3D yacht-sailing simulator/trainer, built with Three.js, that teaches how wind
actually works — apparent wind, sail trim, the no-go zone, tacking, and gybing — through a
guided six-lesson curriculum on open water, plus a free-sail mode.

**Why it exists:** a personal passion project — I sail, and wanted to build a physically-real
(if simplified) sailing model as a hands-on AI-native build, teaching myself and others real
sailing intuition through play rather than reading. No build step, runs entirely offline.

**Status:** working, playable simulator with a real physics model (see docs/RESEARCH.md) and a
complete lesson curriculum.

See [README.md](README.md) for how to run it and the full controls/lesson list.
